4. CASOS DE PRUEBA QUE PREPARÉ PARA LA DEMOSTRACIÓN
-----------------------------------------------------------------------------

a) Prueba de Login Correcto (Puntos 2 y 3 del TP):
   - Ingreso con 'alumno' y '1234'.
   - El servidor valida contra MySQL, me manda la bienvenida y el estado
     pasa a verde: "Conectado como 'alumno'".

b) Prueba de Login Rechazado (Punto 3 del TP):
   - Ingreso con 'alumno' y una clave incorrecta, por ejemplo '9999'.
   - El servidor rechaza la conexión, me muestra la alerta de acceso denegado
     y cierra el socket de inmediato.

c) Prueba de Sesión Duplicada:
   - Con la sesión de 'alumno' abierta, intento conectar otra ventana con
     el mismo usuario 'alumno'.
   - El servidor detecta que ya está conectado y me deniega el segundo acceso
     para evitar colisiones de socket.

d) Prueba de Concurrencia (Punto 1 del TP):
   - Abro tres terminales:
       1) python servidor.py
       2) python cliente.py (inicio como 'alumno')
       3) python cliente.py (inicio como 'javier')
   - En el servidor veo que el contador sube a 2 clientes activos y puedo
     mandar mensajes entre ambos sin que se bloquee ninguna ventana.
